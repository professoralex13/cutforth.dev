## Overview

A high-fidelity Airbus A220 simulation project built for Microsoft Flight Simulator.

## Contribution

I collaborated remotely with an international team to build a complete avionics GUI component library, a class-based Flight Plan Management system with ARINC 424 procedure support, and a staggered-projection aircraft map using HTML canvas.
