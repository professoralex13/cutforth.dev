# CUTFORTH.DEV

This is the source code for my personal CV/portfolio site, welcome!

## Why?

I thought it would be cool to have an interactive portfolio rather than a long PDF document.

This is also an experiment in vibecoding. The initial design and code was generated using Figma. Subsequent code implementation was done with copilot in vscode.
The content is written by me, I ain't gonna use AI for everything. I also wrote this readme file on my own because I know what I'm doing.

## How?
The website uses Typescript React, using Vite as the build tool.
